Home Comfort — кафе «Домашний уют»
Учебное desktop-приложение на Python + PyQt6 + SQLite с архитектурой MVC.

Возможности
регистрация и вход клиента;
отдельный вход администратора;
меню с изображениями и корзина;
оформление заказа, оплата картой/наличными и расчёт сдачи;
сохранение заказов и состава заказа в SQLite;
управление сотрудниками: добавление, изменение, удаление, удаление всех;
заявки соискателей и найм по уникальному коду;
проверка уникальности логина и ID сотрудника;
пароль хранится в виде PBKDF2-хеша с солью.



Запуск
Установите Python 3.10 или новее.
Откройте терминал в папке проекта.
Установите зависимость:
python -m pip install -r requirements.txt
Запустите:
python main.py
SQLite-файл home_comfort.db и таблицы создаются автоматически при первом запуске.

Данные для первого входа администратора
Логин: admin
Пароль: admin12345




Структура
database.py — схема SQLite и подключение;
model.py — модели и операции с данными;
view.py — интерфейс PyQt6;
controller.py — обработчики и связи MVC;
main.py — запуск.
Оплата в проекте демонстрационная: приложение не подключается к банковским сервисам и не списывает реальные деньги.
